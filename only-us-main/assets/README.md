# Assets — placeholder art

All artwork in `assets/images/` is **original placeholder art** created
for this project. It is simple SVG line/shape art in the Only Us palette
(Midnight Purple `#100B1F`, Purple `#7C3AED`, Pink `#FF4D9D`, Lavender
`#E9D5FF`). No logos, photos, or artwork were copied from anywhere.

## Files

| File | Used for |
|---|---|
| `images/logo.svg` | App logo / splash placeholder — heart in a rounded purple tile |
| `images/heart.svg` | Heart icon for the Love tab / empty states |
| `images/empty_chat.svg` | Empty-chat illustration (no messages yet) |

## Replacing them

Replace any of these with final art whenever the real designs are
ready — keep the same file names so no code changes are needed, or
update the references in the app if you rename them. Keep the same
palette so the Midnight Purple theme stays consistent.

If you add raster images (PNG/JPG), prefer WebP or PNG at 2x/3x sizes
and declare them in `pubspec.yaml` under `flutter: assets:`.
